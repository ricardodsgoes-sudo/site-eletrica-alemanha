# DRI Elektrotechnik

Static marketing site for DRI Elektrotechnik in Darmstadt.

## Structure

- `index.html` - home page
- `wallboxen.html` - Wallbox installation landing page
- `pv-anlage.html` - PV systems landing page
- `kundendienst.html` - service and repair landing page
- `datenschutz.html` and `impressum.html` - legal pages
- `assets/img/` - optimized production images
- `styles.css` and `script.js` - shared frontend code
- `_headers` - deployment cache/security headers

The repository intentionally excludes local browser profiles, screenshots, audit exports, source design files, and client originals.
